# Technical Indicators

## When to use
- Screening a stock for a setup, confirming an entry/exit, or setting a stop/target.

## Core indicators (and what they mean)
- **RSI (14)**: >70 overbought, <30 oversold. Mean-reversion uses <30 buy / >70 sell.
- **MACD (12,26,9)**: signal-line cross above = bullish, below = bearish.
- **Moving averages**: 50 vs 200. Price above 200 = long-term uptrend; 50 crossing 200 (golden/death cross) is a trend signal.
- **Bollinger Bands (20,2)**: price touching lower band = oversold; upper band = overbought; squeeze = breakout coming.
- **ATR (14)**: average true range = volatility. Use for stop distance (e.g. 1.5x ATR).
- **Volume**: confirm moves — a breakout on high volume is real; low volume is suspect.

## Practical use (penny stocks)
- Prefer **RSI + volume** for mean-reversion on $1-5 stocks.
- Confirm with price vs 50/200 MA before entering.
- Set stop using **ATR**, not a fixed % only — adapts to volatility.

## Pitfalls
- Penny stocks are noisy; a single indicator is unreliable — combine 2+.
- RSI on very low-liquidity stocks gives false signals — check volume first.
- Don't chase a stock that already moved big (extended).

## Output
- State the indicators, their values, and the concrete signal (buy/sell/neutral) with the reasoning.
